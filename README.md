# Emissão parcelada SABRE (Streamlit)

Gera os comandos SABRE de autorização (etapa 1) e emissão parcelada (etapa 2).

    pip install -r requirements.txt
    streamlit run app.py

Sem login: cada aba do navegador é uma sessão independente. Nenhum dado (inclusive de cartão)
é gravado em arquivo, banco ou log; tudo fica só na memória da sessão.
